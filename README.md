# blinky-duck
## Why I made this
An LED board shaped like a duck for adorableness :3

I wanted to create this project to learn more about the fundamentals of PCB design, because I felt like i jumped straight into things like hackpads without appreciating the fundamentals and actually understanding what everything does.

I learned about various different components, like a potentiometer, from this project, and I believe my skills have improved with this mini ducky <3
